# 终端区分「你 / 模型 / 命令输出」的视觉样式

日期：2026-06-21

## 问题

命令行回看时，**用户输入、模型文字、命令输出三者都是默认色、顶格的纯文本**，糊成一团，分不清是谁说的。提示符那个青色 `>` 只在当下有用，翻历史就失去区分作用。

## 目标

让三种内容在终端里一眼可分，保持项目「最小、纯标准库、重中文注释」的风格。改动只落在 `main.go` 与 `agent/terminal.go`，核心循环 `agent/agent.go` 不动。

## 方案：角色标签 + 颜色

| 角色 | 现在 | 改成 | 位置 |
|------|------|------|------|
| 用户输入 | 青色 `>` + 默认色文字 | 青色 `你 ›` + 默认色文字 | `main.go` REPL 提示符 |
| 模型文字 | 默认色顶格 | 绿色加粗 `助手` 标签 + 默认色正文 | `terminal.go` `AssistantText` |
| 工具确认 | 黄色 `▶ name args` | 黄色 `▶ name args`，2 空格缩进 | `terminal.go` `ConfirmTool` |
| 命令输出 | 默认色 | 暗灰 `\033[2m…\033[0m` | `terminal.go` `ToolOutput` |

### 取舍说明

- **工具确认行保持黄色、不调暗**：它是执行前的安全闸，黄色 = 「要动手了，注意看」，调暗会削弱警示。只加缩进做视觉分组。
- **工具参数保持原样 JSON**（如 `▶ bash {"command":"ls"}`），不解析成 `· ls`：解析参数会让 UI 层去懂每个工具的参数结构，破坏现在干净的分层（UI 不依赖具体工具）。
- **命令输出整体包一层 `\033[2m…\033[0m`**：若某条命令自己输出了带颜色的内容（`ls --color`、彩色 git diff），其内部的颜色重置码可能提前取消暗灰——对纯文本输出无影响，属可接受的边界情况。
- **「助手」标签每段都带**：核心循环每出一段 assistant 文字就调一次 `AssistantText`，所以多步对话里每段都认得出。

## 测试

`TerminalUI` 现无专门测试。新增 `agent/terminal_test.go`，用注入的 `bytes.Buffer` 断言渲染结果里含有预期的标签/转义标记（绿色「助手」、暗灰包裹、黄色 `▶` 等）。现有 `integration_test.go` 用 `fakeUI`，不受影响。
